## 시나리오 1. 문제 풀이(개인)

### 1. 문제 목록에서 ‘연쇄 폭발 만들기’ 문제 선택

![스크린샷 18.png](images/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_18.png)

### 2. 프롬프트 입력

- 오른쪽 하단 프롬프트 입력창에 입력 후 제출 버튼(위 화살표 모양) 눌러 제출

#### 2.1. 1회차 입력

```
지금 게임에서 클릭하면 폭발이 하나만 생기는데, 점이 폭발에 닿아서 터지면 그 자리에서도 새로운 폭발이 생기게 해줘.

새로 생긴 폭발도 다른 점들을 터뜨릴 수 있게 해서 연쇄적으로 폭발이 이어졌으면 좋겠어.

폭발은 여러 개가 동시에 존재할 수 있어야 하고, 같은 점이 여러 번 터지지는 않게 해줘.

처음 클릭한 폭발부터 몇 번째 연쇄인지 단계도 계산하고, 최대 몇 단계까지 이어졌는지 화면에 보여줘.

연쇄 단계가 높을수록 점수도 더 많이 주고, 폭발이 전부 끝나면 몇 개를 터뜨렸는지, 최대 연쇄 단계, 점수, 성공 여부를 보여줘.

전체 점의 70% 정도를 터뜨리면 성공으로 해주고, 연쇄 단계에 따라 폭발 색을 7가지가 반복되도록 하고 크기도 조금씩 다르게 보여줘.

기존 게임의 느낌은 최대한 유지하면서 수정해줘.
```

- 프롬프트 반영 코드 결과 확인
    
    ![스크린샷 19.png](images/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_19.png)
    
- 프롬프트 실행 결과 기록 확인
    
    <img src="images/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_20.png" width="450" alt="스크린샷 20">
    
- 프롬프트 반영 결과 확인(게임)
    
    <img src="images/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_21.png" width="450" alt="스크린샷 21">
    - 게임 플레이하며 구현 진척도 확인

#### 2.2. 2회차 입력

```
폭발이 연쇄적으로 잘 터지긴 하는데, **지금은 각 폭발이 몇 단계인지 잘 모르겠어.**

각 폭발이 몇 번째 연쇄인지 폭발과 함께 보이도록 숫자나 텍스트로 표시해줘.

처음 클릭한 폭발은 1단계, 그 다음에 터진 폭발은 2단계처럼 보이면 좋겠어.

너무 복잡하지 않게, 화면에서 바로 알아볼 수 있게 수정해줘.
```

- 연쇄 단계를 시각화하라는 추가 요구사항 반영
- 프롬프트 반영 코드 결과 확인
    
    ![스크린샷 22.png](images/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_22.png)
    
- 전체 토큰 사용량 확인(1회차 + 2회차)
    
    <img src="images/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_23.png" width="450" alt="스크린샷 23">
    
- 프롬프트 반영 결과 확인(게임)
    
    <img src="images/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_24.png" width="450" alt="스크린샷 24">
    
    - 폭발 별 단계가 표시되도록 반영된 것을 확인

#### 2.3. 3회차 입력

```
지금 연쇄 폭발은 잘 보이는데, 폭발 원이 너무 크게 퍼지고 있어.

**폭발의 최대 범위는 40으로 줄이고, 각 폭발은 생성된 뒤 105프레임 동안 유지되도록 수정해줘.**

폭발이 커지고 유지되다가 사라지는 애니메이션도 105프레임의 수명에 맞게 조정해서, 폭발 반지름이 음수가 되거나 화면이 멈추지 않도록 해줘.

기존 연쇄 폭발, 단계 표시, 점수 계산, 성공 판정 기능은 그대로 유지해줘. 
```

- 폭발 최대 범위 지정 & 폭발 유지 프레임 지정
- 프롬프트 반영 코드 결과 확인

    ![스크린샷 26.png](images/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_26.png)
    
- 프롬프트 반영 결과 확인(게임)
